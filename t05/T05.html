체크리스트

✅ 1. 요구사항 정의 — 작은 사진은 자유 이동·크기조절 가능, 개수 제한 없음, 기본 크기는 배경의 25%
✅ 2. UI 배치 설계 — '작은 사진 삽입' 버튼을 기존 '글자 추가' 옆에 배치
✅ 3. 레이어 데이터 구조 — 텍스트/이미지 레이어를 동일한 layer 배열로 통합 관리
✅ 4. 렌더링 구현 — 작은 사진이 스테이지 위에 실제로 표시됨
✅ 5. 드래그·크기조절 구현 — 우측 하단 핸들로 크기조절, 본체 드래그로 이동
✅ 6. 필터 적용 범위 — 배경 필터와 선택한 작은 사진 필터를 분리 적용
✅ 7. 레이어 순서 — 선택 레이어가 앞으로 오며, 앞으로/뒤로 보내기 기능 제공
✅ 8. 다운로드 — 현재 편집 화면을 PNG/JPEG로 저장
✅ 9. 비율 정합성 — 1:1, 4:3, 16:9 변경 시 레이어 위치·크기를 비율에 맞춰 보정
✅ 10. 크로스 디바이스 — Pointer Events와 터치 조작을 사용하여 데스크톱·모바일 조작 대응
